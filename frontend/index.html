Performance Analysis & Experimental Findings
Testing vs. Validation Alignment

The Siamese model delivers 94.2% Testing Accuracy on held-out test paddy leaves, aligning with the 94.4% Peak Validation Accuracy. This minimal 0.2% generalization gap demonstrates that the model generalizes robustly to real-world field images without overfitting.

cGAN Data Augmentation Role

Conditional GAN (cGAN) synthesized realistic synthetic lesion patterns for minor pathology classes, balancing the training distribution. This prevents class imbalance collapse and stabilizes validation loss descent.

Dual-Stream Siamese Fusion

Shared weights between top-view (T1) and bottom-view (D1) EfficientNet-B0 streams produce a rich 2560D fused feature vector, enabling fast convergence around Epoch 28 and achieving minimum cross-entropy loss at 0.133.
